# 中文提交信息

标题采用 `<类型>[可选 作用域]: <描述>`。有作用域时用半角圆括号包住，例如 `fix(登录): 修复会话过期后的跳转`。省略作用域时，直接在类型后加半角冒号和一个空格，例如 `feat: 支持按状态筛选订单`。 [约定式提交 1.0.0](https://www.conventionalcommits.org/zh-hans/v1.0.0/)

- 类型使用小写英文标识。新增功能用 `feat`，修复问题用 `fix`。按实际改动也可用 `docs`、`refactor`、`perf`、`test`、`style`、`build`、`ci` 或 `chore`，并沿用仓库已有的类型约定。
- 作用域用于指出主要受影响的模块或功能，优先沿用仓库已有叫法。标题描述和正文使用中文，代码标识符、工具名和路径保留原样。
- 标题简洁说明这次提交的主要变化。当标题无法充分交代关键细节时，在空一行后补充中文正文，说明改动原因、相关行为或影响。一个标题已经清楚时，省略正文。

完整的标题和正文示例见 [Good 案例](good-examples.md)。
