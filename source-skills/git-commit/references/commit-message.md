# 中文提交信息

标题用 `<类型>[可选作用域]: <描述>`。作用域用半角圆括号，冒号用半角并跟一个空格。示例见[正确案例](good-examples.md)。[约定式提交 1.0.0](https://www.conventionalcommits.org/zh-hans/v1.0.0/)

- 类型用小写英文。新增功能用 `feat`，修复用 `fix`。按改动及仓库约定也可用 `docs`、`refactor`、`perf`、`test`、`style`、`build`、`ci` 或 `chore`。
- 作用域指主要受影响的模块或功能，优先沿用仓库叫法。描述和正文用中文，代码标识符、工具名和路径保留原样。
- 标题简洁概括主要变化。仅在标题交代不完关键细节时，空一行补充原因、行为或影响。
