# 错误案例

- `src/login.ts` 已暂存登录修复，另有未暂存的日志调整。`git add -- src/login.ts` 会把日志调整也暂存。`git commit -m 'fix(登录): 修复会话过期后的跳转' -- src/login.ts` 会直接按路径取工作区内容，把日志调整一并提交。
- 暂存区为空，本次只增加订单筛选和测试，实现文件含旧改动，另有未跟踪的草稿。根目录执行 `git add .` 会加入旧改动和草稿。即使指定 `git add -- src/order-filter.ts tests/order-filter.test.ts`，仍会暂存实现文件中的旧改动。
- `feat[订单]：支持按状态筛选订单` 误用方括号和全角冒号，正确写法为 `feat(订单): 支持按状态筛选订单`。
- `feat(订单): add status filter` 的描述应改用中文说明具体改动。`chore: 更新代码` 既未写明变化，类型也未体现新增功能。
- 标题已写 `feat(订单): 支持按状态筛选订单` 时，省略“新增订单状态筛选功能”这类重复正文。
- 本地提交后执行 `git push` 会发布到远端，超出本 Skill 的范围。
